# Runzivo ideas and public roadmap

This repository hosts product feedback for all of Runzivo, alongside the CLI source and releases. Everyone is welcome to suggest improvements, comment, and vote. A GitHub account is required to participate; reading is public.

## Suggest and vote

- Search [Ideas](https://github.com/Runzivo/rzv-cli/discussions/categories/ideas) before opening a request.
- Upvote an existing idea with the upvote arrow and add your use case in a comment.
- [Suggest a feature](https://github.com/Runzivo/rzv-cli/discussions/new?category=ideas) when no existing idea covers your problem. Explain the problem, desired outcome, impact, and current workaround.

## Follow the decision

The [public roadmap](https://github.com/orgs/Runzivo/projects/3/views/1) tracks reviewed requests. The team links selected discussions to public tracking issues. Votes inform priorities alongside customer impact, effort, and dependencies. There is no fixed vote threshold or promised delivery date.

| Status      | Meaning                                                   |
| ----------- | --------------------------------------------------------- |
| Considering | Reviewing the problem and possible approaches.            |
| Planned     | Selected for future work, with no promised delivery date. |
| In progress | Work has started.                                         |
| Shipped     | Available to customers, with a release link.              |
| Not planned | Not being pursued, with an explanation.                   |

The board starts empty while the first ideas are reviewed. Discussion upvotes are the voting mechanism. The board records decisions and progress.

## Bugs, private help, and code contributions

Report reproducible CLI bugs in this repository’s Issues. For private account or billing help, email support@runzivo.dev. Follow [SECURITY.md](SECURITY.md) for security reports. Never post credentials or private customer information in public discussions.

Product feedback is welcome. The CLI repository still does not accept outside code contributions.
